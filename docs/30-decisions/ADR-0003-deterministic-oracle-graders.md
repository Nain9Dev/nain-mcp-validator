# ADR-0003: Deterministic oracle graders, no LLM judge

- Status: Proposed
- Spec: `specs/001-agent-eval-harness`

## Context

A judge model would add the same unreliability that the harness is meant to measure.

## Decision

Task meshes are generated by code with a known defect, and the server's own domain checks confirm each declaration (self-check). Graders are pure functions over the trace and the declaration. They never call a model.

## Consequences

- Grading is repeatable and cheap.
- The harness can only grade properties the validator can decide. Free-text quality is out of scope.

## Alternatives discarded

- LLM-as-judge: unreliable and costly for a question that has an exact answer.
